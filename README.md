# Rental-DB
System bazodanowy do obsługi wynajmu mieszkań (PostgreSQL): ogłoszenia, umowy, płatności, historia najmu i profile najemców. Projekt z baz danych — schemat w 3NF, widoki, funkcje i wyzwalacze PL/pgSQL, transakcje z poziomami izolacji oraz role i uprawnienia. Podział pracy na 4 sekcje wg obszarów.
